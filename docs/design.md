# Lite CDP：顧客地圖

## 設計

以鈷藍、天空藍、細網格與連接節點，呈現從造訪到身份與行為理解的顧客地圖。桌面移除側欄，改成上方品牌列、網站切換與橫向功能導覽；總覽把訪客身份概況放在前面，再看近期活動、來源與名單。名單、個人時間軸、標籤與分群保有完整操作寬度。

- 字體使用已有的本機 Noto Sans TC，搭配平台的 Avenir Next 作英文與數字；移除未使用的 Inter 依賴。沒有外部字型請求。
- 深色模式保留產品色彩；手機使用選單抽屜、單欄內容與可捲動的資料表。
- 手機的身份概況改成直向版面，數字仍並排；桌面與手機網站選擇器使用不同標籤 ID。身份與標籤數字是資料概況，並非追蹤轉換率的漏斗。
- 動畫尊重 `prefers-reduced-motion`，保留表單標籤、鍵盤焦點與主題選擇功能。

## 實作與後端檢查

1. 首次設定原先先查使用者數量，再建立帳號。六個同時送出的請求均可能通過檢查，實際測試建立了六名管理員。現在以單一 SQLite `INSERT … SELECT … WHERE NOT EXISTS` 原子寫入，只允許一個成功，其他回覆 `409 Conflict`。驗證與 Argon2 雜湊在寫入前完成。
2. 新增 `concurrent_setup_creates_exactly_one_administrator` 整合測試：修正前失敗（6 個成功），修正後一個成功、五個衝突，資料庫恰有一個帳號。
3. 檢查登入 session、同源保護、輸入驗證、網站成員範圍、匯出與管理員操作，並執行原有整合測試。網站範圍的名單／事件／標籤／分群、匯出、辨識合併、保留期限與追蹤輸入均由原有測試涵蓋。
4. Vite 字串形式的代理設定會改寫 `Host`，導致瀏覽器登入被同源保護拒絕。代理改成明確保留 `Host`，並透過真實瀏覽器登入驗證。分群編輯測試改為等待非同步資料填入，避免在欄位已掛載但資料尚未套用時斷言。

5. 桌面與手機主題控制共用 Layout 的狀態，避免手機選深色後，桌面按鈕仍停在舊選項。新增回歸測試驗證雙控制同步，並能切回淺色。

## 圖像與公開檢查

`docs/images/cover.svg` 是可編輯的程式碼原生封面。所有 PNG 都由新介面重新擷取，舊版封面與未使用截圖已移除。`docs/capture-screenshots.py` 讀取 `DEMO_URL`、`DEMO_PASSWORD`；帳密不寫入專案。重拍需要 Python Playwright 與 Chromium，使用內建 demo 產生的虛構資料。

檢查目前追蹤檔案與 Git 所有可達歷史 blob（97 個），未找到私鑰、常見雲端／GitHub／Slack token 樣式、追蹤中的 `.env` 或資料庫檔案。範例資料使用保留的 example 網域。這是程式碼、規則掃描與畫面檢查的結果，不代表完整滲透測試。未測試外部 SMTP 或真實第三方 webhook，也未在這輪重新建立 Docker 映像檔。
